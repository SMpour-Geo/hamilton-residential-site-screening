
# Residential Site Screening & Spatial Decision Support

### Hamilton, New Zealand - Independent GIS Portfolio Case Study

  GIS - ArcGIS Pro - ArcPy - Spatial Analysis - Automation - Decision Support

## Project Overview

This independent geospatial project demonstrates an automated workflow for preliminary residential parcel screening in Hamilton, New Zealand.

The project integrates land parcel information, district plan zoning, and an illustrative flood scenario to demonstrate how spatial analysis can support the early stages of land-development investigations.

The workflow was designed to deliver reproducible geospatial analysis, transparent screening criteria, and professional client-facing outputs.


## Project Objectives
- Integrate publicly available geospatial datasets.
- Identify and examine parcels across different zoning categories.
- Calculate parcel-level spatial relationships and screening indicators.
- Demonstrate multi-class flood-overlay analysis using synthetic test data.
- Automate spatial processing and reporting with ArcPy.
- Produce maps, spreadsheets, and supporting documentation.

## Methodology
The workflow includes:

1. Spatial data acquisition and validation
2. Study area definition
3. Parcel extraction and preparation
4. Zoning intersection and area calculations
5. Preliminary parcel screening
6. Synthetic flood scenario overlay
7. Quality assurance and reporting
8. Cartographic visualisation and deliverable generation

## Important Limitations
This is an independent portfolio demonstration, not an official planning assessment.
Flood exposure classes are synthetic test inputs and do not represent measured or modelled flood hazards.
Zoning-based screening does not establish legal development rights, engineering feasibility, or resource consent eligibility.

## Professional Focus
This case study demonstrates practical experience in spatial data integration, geoprocessing automation, parcel-level analysis, GIS quality assurance, and client-oriented geospatial reporting.
